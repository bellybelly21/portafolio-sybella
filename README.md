# 🚀 Portafolio Profesional v3.0

> Mi portafolio web personal, diseñado desde cero para reflejar mi evolución hacia el desarrollo fullstack. Minimalista y de alto rendimiento.

🌐 **Sitio web en vivo:** [sybellasandoval.cl](https://sybellasandoval.cl)

---

## 🛠️ Tecnologías y Herramientas

* **Framework:** Next.js (App Router)
* **Estilos:** Tailwind CSS
* **Animaciones e Iconos:** Framer Motion y Lucide React
* **Base de Datos:** MongoDB (gestionado con Mongoose)
* **Correos:** Resend para las alertas del formulario de contacto
* **Seguridad:** Google reCAPTCHA v3
* **Deploy:** Cloudflare

---

## ✨ Qué incluye este proyecto

* **Formulario de contacto:** Conectado directamente a MongoDB y protegido contra spam con reCAPTCHA v3.
* **Notificaciones automáticas:** Envío de correos a través de la API de Resend cada vez que alguien escribe una consulta.
* **Blog:** Espacio para compartir artículos.
* **Mis proyectos:** Para mostrar la historia y el proceso detrás de cada cosa que he hecho.
